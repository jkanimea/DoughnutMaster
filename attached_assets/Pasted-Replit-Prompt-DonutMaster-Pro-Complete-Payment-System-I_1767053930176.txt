Replit Prompt: DonutMaster Pro - Complete Payment System Included
PROJECT TITLE: DonutMaster Pro - Full Bakery Management System with Secure Payments
PROJECT OVERVIEW:
Build a comprehensive mobile-responsive donut/bakery sales platform with complete payment processing, inventory management, financial reporting, and automated testing. The system must handle both e-commerce payments (Visa/Mastercard via Stripe) and traditional bank transfers for New Zealand banks, with secure credit card storage for returning customers.

CORE TECHNOLOGY STACK:
Frontend: Next.js 14 (App Router) with TypeScript & Tailwind CSS

Backend: Next.js API Routes with Server Actions

Database: PostgreSQL with Prisma ORM

Payment Processing: Stripe for cards, Bank Transfer for NZ banks

Authentication: NextAuth.js with credentials + social logins (Phase 2)

Mobile: Responsive design with touch-optimized components

Security: PCI-compliant card handling, data encryption

Testing: Jest (unit/integration), Cypress (E2E), 80%+ coverage requirement

Deployment: Replit-ready with PostgreSQL integration

ESSENTIAL BUSINESS FEATURES:
1. USER MANAGEMENT SYSTEM:
Three Registration Methods:

Admin manual registration (full control)

Self-registration via public dashboard

Social login via Facebook/Gmail (Phase 2)

User Types & Permissions:

Customers: Place orders, view history, manage payment methods

Administrators: Full system access, financial reports, inventory control

2. PRODUCT & ORDERING SYSTEM:
Base Product: Donuts sold in bags (10 donuts = $10 per bag)

Multi-product Support: Admin can add buns, pastries with custom pricing

Order Flow: Bag selection → Date selection (no Friday/Saturday) → Payment → Confirmation

Delivery Options: Customer pickup or admin delivery

Quantity Calculation: 1 bag = 10 items, price scales linearly

3. PAYMENT SYSTEM (COMPREHENSIVE):
A. STRIPE INTEGRATION (Credit/Debit Cards):

Supported Cards: Visa, Mastercard, American Express

Secure Card Storage: PCI-compliant tokenization via Stripe Customer API

Card Management: Customers can save multiple cards, set default, delete

Security Features:

Never store full card numbers locally

Show only last 4 digits and expiry in UI

Stripe Elements for secure iframe card input

3D Secure authentication for high-risk transactions

CVV required for each transaction (not stored)

B. BANK TRANSFER (New Zealand):

Supported Banks: All major NZ banks (ANZ, ASB, BNZ, Westpac, etc.)

Payment Details Generation: Unique reference number per order

Manual Verification: Admin marks transfers as received

Automated Reminders: Send bank details via email/SMS

Receipt Upload: Customers can upload transfer receipts

C. CREDIT/PAY LATER SYSTEM:

Credit Requests: Customers can request delayed payment

Admin Approval: Manual review of credit requests

Custom Terms: 7, 14, 30-day payment windows

Automated Reminders: Payment due alerts

Overdue Tracking: Escalation process for late payments

D. FREE DONATIONS:

Admin can issue free products for promotions/loyalty

Separate tracking from revenue calculations

Reason tracking (promotion, complaint, loyalty)

4. ORDER SCHEDULING & ALERTS:
Date Restrictions: No deliveries on Friday or Saturday

Admin-set Availability: Pre-configured delivery dates

Customer Choice: Select next available non-Friday/Saturday date

Automated Alerts:

Order reminders (24 hours before)

Payment due notifications

Credit card expiry warnings

Bank transfer reminders

5. INVENTORY & EXPENSE MANAGEMENT:
Ingredient Tracking: Flour, sugar, milk, oil, cream, butter with unit costs

Batch Production: Track costs per production batch

Misc Expenses: Electricity, labor, packaging, rent

Auto-calculation: System calculates ingredients needed based on orders

Low Stock Alerts: Automatic reorder notifications

Recipe System: Define exact ingredient quantities per product

6. FINANCIAL REPORTING & ANALYTICS:
Admin Dashboard Must Include:

Real-time Financial Overview:

Revenue (paid orders)

Expenses (ingredients + operational)

Profit (calculated automatically)

Profit margin percentage

Visual Charts:

Revenue vs Expenses vs Profit (pie chart)

Sales trend by day/week/month (line chart)

Payment method distribution (donut chart)

Expense breakdown by category (bar chart)

Detailed Reports:

Daily/weekly/monthly financial summaries

Product profitability analysis

Customer purchase patterns

Payment success/failure rates

Bank transfer pending/cleared status

7. SECURITY & COMPLIANCE FEATURES:
PCI DSS Compliance: Via Stripe integration

Data Encryption: All sensitive data encrypted at rest

Access Controls: Role-based permissions

Audit Logging: Track all payment-related actions

GDPR/Privacy: Data minimization, right to deletion

Secure Session Management: JWT with refresh tokens
